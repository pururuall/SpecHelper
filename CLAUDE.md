# CLAUDE.md — SpecHelper

Смотри подробные правила и стандарты разработки в [AGENTS.md](AGENTS.md).

## Главные правила:
1. Релизы на GitHub создавать только через `gh release create`, проверяя доступность URL из `version.json`.
2. Все текстовые файлы сохранять строго в UTF-8 без BOM (никаких кракозябр в `.gitignore` и `version.json`).
3. Бережно относиться к базам данных в `databases/` — не перезаписывать без спроса.
4. Временные скрипты создавать строго в `.scratch/`.
